# KEEP法：滑らかな流れの釣合いと限界を検証する

KEEPは**kinetic-energy and entropy preserving**の略です。東北大学のYuichi Kuya、Kosuke Totani、Soshi Kawaiによる、圧縮性保存方程式間の低散逸な釣合いを目指す研究です。[2018年の原論文](https://doi.org/10.1016/j.jcp.2018.08.058)を出発点とし、著者の[2022年会議解説](https://www.iccfd.org/iccfd11/assets/pdf/papers/ICCFD11_Paper-0401.pdf)、特に第2.2節・式9が本実装の直交座標流束を示します。

展示は**原型の2次精度・算術平均・直交座標流束**と周期境界、古典的RK4です。後のKEEPすべてを実装するものではありません。[滑らかな渦の時間発展](#/movies?case=keep-vortex)を再生できます。

![原型KEEPの等エントロピー渦：密度、解析参照誤差、収束、エントロピー代理量](figures/keep-vortex.png)

## どの量を保存するか {#which-quantities-should-be-preserved}

滑らかな周期非粘性流では、質量、運動量、全エネルギーは保存量です。ただし圧縮性流の運動エネルギー単独は一般に**一定ではありません**。圧力仕事が運動・内部エネルギーを交換します。K=integral rho |u|²/2として、

\[
\frac{dK}{dt}=\int p\,\nabla\cdot u\,dV.
\]

です。運動エネルギー整合な対流離散化は、質量・運動量の不整合な積の公式から偽の運動エネルギー源を作るべきではありません。圧縮性渦にdK/dt=0を課すこととは違います。

無次元のエントロピー代理量を、

\[
S_* = \int\rho\log\left(\frac{p}{\rho^\gamma}\right)dV.
\]

で測ります。固定組成の理想気体では、物理エントロピーとの差は定数係数と質量の加法項です。初期等エントロピー状態でS_*がほぼゼロなら、初期質量あたりの変化が有用です。初期S_*で割ると条件が悪くなります。

## 実装した2点流束 {#the-implemented-two-point-flux}

上線を左右の算術平均、u_nを直交面の法線速度、e=p/[rho(gamma−1)]とすると、基準流束は、

\[
\begin{aligned}
C&=\overline\rho\,\overline u_n,\\
F_{\rho u_i}&=C\,\overline u_i+\overline p\,\delta_{in},\\
F_E&=C\left[\frac12\boldsymbol u_L\cdot\boldsymbol u_R+\overline e\right]
+\frac12(u_{n,L}p_R+u_{n,R}p_L).
\end{aligned}
\]

です。質量流束はCです。交差速度の運動項と交差圧力仕事には意味があり、物理流束全体の都合のよい平均に置き換えると離散エネルギー交換が変わります。空間2次の中心2点流束差分法で、リーマンソルバーの散逸はありません。

テストでは同一状態の整合性、左右対称性、主変数の周期保存、半離散運動エネルギー・圧力仕事の恒等式を検証します。RK4は時間打切り誤差を加え、すべての半離散恒等式を厳密に継承しません。

## 最初の適切なテスト：滑らかな等エントロピー渦の移流 {#appropriate-first-test-smooth-isentropic-vortex-advection}

gamma=1.4、周期正方形[−10,10]²、背景速度(1,0.5)、渦強度beta=3です。移動中心からの相対座標をX、Y、r²=X²+Y²として、参照解は、

\[
\begin{aligned}
u&=1-\frac{\beta Y}{2\pi}e^{(1-r^2)/2},&
v&=0.5+\frac{\beta X}{2\pi}e^{(1-r^2)/2},\\
T&=1-\frac{(\gamma-1)\beta^2}{8\gamma\pi^2}e^{1-r^2},&
\rho&=T^{1/(\gamma-1)},\qquad p=\rho^\gamma.
\end{aligned}
\]

です。全平面の渦は解析的に移動します。長さ20の箱の最小像座標では、この設定の境界裾が浮動小数点で有意でない程度となり、顕著な周期境界の跳びを避けます。解析温度の正値性を明示的に確認します。

静止図の研究は48²、96²、192²セル、CFL0.25、t=1です。密度点値L1、主保存量のずれ、質量あたりのS_*変化を報告します。別の96²計算でCFLを半分にし、時間刻みの寄与を調べます。[測定記録](figures/keep-vortex.json)に実際の誤差を示し、滑らかな解の期待空間次数は2です。一方、動画は96²でt=4までの定性的な時間履歴で、細分化の代わりではありません。

## 次に適切なテスト {#appropriate-next-tests}

**圧縮性・非粘性3次元Taylor–Green渦**は主要なKEEPテストです。周期箱[0,2 pi]³、参照密度、gamma、初期Mach数、速度振幅、初期圧力摂動、時間積分を固定します。格子・時間細分化で全エネルギー、運動エネルギー、圧力膨張、エントロピー、密度・温度RMS、解像スペクトルを追い、圧力仕事の交換と数値散逸を分けます。原論文は非粘性等方乱流も扱います。初版にはこれらの3次元計算はなく、2次元断面では3次元の渦伸長を置き換えられません。

滑らかな**一定圧力の密度波**は圧力・速度平衡を検証する有用な診断ですが、その性質は流束の変種に依存します。本実装の原型算術平均流束はこの初期値に非ゼロの半離散圧力残差を生じ、通過したとせず限界をテストに記録します。[Shimaら（2021）](https://doi.org/10.1016/j.jcp.2020.110060)は圧力平衡保存の分割形を研究しています。

## エントロピー、衝撃波、方式の版に関する注意 {#caveats-entropy-shocks-and-the-scheme-version}

1. **保存型という名称は丸め誤差までの厳密なエントロピー保存ではありません。** 著者は2022年解説で改善された挙動と厳密保存を区別します。[Tamaki・Kuya・Kawai（2022）](https://doi.org/10.1016/j.jcp.2022.111494)は残る誤差と調整可能な近似次数のKEEP再定義を扱います。本実装はその再定義や厳密な対数平均エントロピー保存流束ではありません。
2. **衝撃波にはエントロピー生成が必要です。** 散逸なしの中心流束には、非振動で許容される衝撃波を選ぶ一般的な仕組みがありません。Sod、Shu–Osher、二重Mach反射を、この無安定化の基準法の受入れテストにはしていません。限界や振動の診断として衝撃波管を解くことはできますが、検証済みの衝撃波捕獲とは表示すべきではありません。KEEPを基にした全手法がすべての衝撃波管を解けないという普遍的主張にもできません。
3. **衝撃波安定化は手法を変えます。** センサー、人工粘性、風上混合、フィルター、他のエントロピー安定構成には独自の定義と検証が必要です。衝撃波・接触波の厚み、振動、正値性、追加散逸を記録し、滑らかな基準法と安定化拡張を分けます。ここにその拡張はありません。
4. **正値性定理はありません。** 表示した滑らかな計算の正密度・正圧力は、真空近傍や任意の解像度不足に対する頑健性を示しません。非物理状態では切り詰めず停止します。
5. **時間積分と境界も重要です。** [Asada・Maruyama・Kawai（2024）](https://doi.org/10.1016/j.compfluid.2023.106143)は時間方向の保存を扱います。本実装のRK4・周期一様格子は、その方式、高次・曲線座標KEEP、非整合節点処理、壁モデル、実用LESを実装していません。

## 再現 {#reproduce}

```bash
python scripts/build_keep.py
python -m pip install '.[movies]'
python scripts/build_movies.py
```

最初のコマンドが滑らかな解の誤差図とソース記録を作り、動画ビルドが[動画ギャラリー](movies.md)へKEEP渦を加えます。[衝撃波テスト](benchmarks.md)、[カーバンクル](carbuncle.md)、[シンプレクティックHamilton写像との違い](symplectic.md)も参照してください。流体のエネルギー・エントロピー整合性と、力学時間写像のシンプレクティック性は異なります。
